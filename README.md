# Ostupchuk landing

Стартовый проект лендинга на Nuxt 4 и TypeScript.

## Требования

- Node.js 22+
- Yarn 1.22+

## Установка

```bash
yarn install
```

## Разработка

Локальный сервер будет доступен на `http://localhost:3000`:

```bash
yarn dev
```

## Проверки

```bash
yarn typecheck
yarn format:check
```

## Production-сборка

```bash
yarn build
```

Предпросмотр production-сборки:

```bash
yarn preview
```
